# Crystal UI

A complete, self-contained UI framework for Roblox — windows, tabs, and a
full component set (buttons, toggles, sliders, dropdowns, multi-select,
keybinds, color pickers) wrapped in a clean, modern aesthetic with live
theme switching.

Bring-your-own-logic: every component just exposes a callback, so Crystal
UI has no game-interaction code of its own — it's purely the interface
layer for whatever you build on top of it.

## Features
- 4 built-in themes + custom theme support
- Flag-based config system with JSON save/load
- Draggable, resizable, minimizable windows with live tab search
- Toast notifications, tooltips, watermark overlay
- Optional key system with save-key and attempt limits
- Single file, no external dependencies
